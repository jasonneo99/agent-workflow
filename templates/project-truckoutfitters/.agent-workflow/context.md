# Truck Outfitters Unlimited Context

Truck Outfitters Unlimited is a production-facing business website. The workflow should prioritize clarity, trust, conversion, mobile usability, SEO basics, and safe handling of WordPress-adjacent assets.

Important areas:

- `index.html`: root landing page.
- `site/`: primary site assets and pages.
- `live-site/`: captured or mirrored live-site state.
- `homepage-modern/`: modernized homepage work.
- `seo/`: SEO exports, notes, or related assets.
- `tools/`: local helper scripts.

Production posture:

- Prefer review and validation before broad changes.
- Preserve existing branding, contact paths, and business-critical content.
- Avoid deleting captured assets or generated site snapshots without explicit direction.
- Keep recommendations compact and actionable.
