# Agent Workflow Plugin Support

For installation help, workflow questions, and usage discussions, use the
[Agent Workflow Discussions](https://github.com/jasonneo99/agent-workflow/discussions)
page. Search existing discussions before opening a new one.

For reproducible software defects, use the repository's
[issue tracker](https://github.com/jasonneo99/agent-workflow/issues) when issue
creation is available to your account. Include the plugin version, operating
system, Node.js version, relevant error text, and a minimal reproduction.

For security vulnerabilities, follow the private reporting instructions in the
repository [Security Policy](https://github.com/jasonneo99/agent-workflow/security/policy).
Do not post credentials, private source code, provider keys, project artifacts,
or other sensitive information in a public discussion or issue.
