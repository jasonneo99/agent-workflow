# Skills-only submission notes

## Submission type

Choose **Skills only** in the OpenAI plugin submission portal.

This package intentionally contains no MCP server. It provides discovery and
onboarding for the separately installed, self-contained local Codex plugin.

## Listing boundary

- No hosted Agent Workflow service is offered.
- No reviewer credentials or MCP demo recording are required for this
  skills-only submission.
- The package contains no payment or purchasing workflow.
- The full local plugin is installed from the public Git marketplace and keeps
  project execution on the user's machine.

## Portal fields requiring publisher confirmation

- Verified developer or business identity
- Supported countries or regions
- Commerce and policy attestations completed by the authorized developer

## Suggested review prompts

1. `Help me install Agent Workflow locally in Codex.`
2. `Explain what this directory plugin can do without the full local plugin.`
3. `Can I use Agent Workflow from ChatGPT without installing anything locally?`
4. `How does the Agent Workflow Studio relate to the local runtime?`
5. `Check whether Agent Workflow is already available in this Codex project.`

The skill must explain its limits, provide the supported installation commands,
and avoid claiming MCP tools or local project access when they are unavailable.
